# Pokédex Nexus

A feature-rich Pokédex app built with **Flutter**, targeting **Android APK**.

## Tech Stack

- **Flutter** (Dart)
- **Riverpod** — state management
- **Dio** — HTTP client
- **Hive / Isar** — local offline storage
- **GoRouter** — navigation
- **Material 3** — UI design system

## Features

- Browse all Pokémon (Gen I–IX)
- Detailed stats, types, abilities, moves, evolutions
- Offline-first caching
- Search & filter by type/generation
- Favorites
- Team builder
- Compare Pokémon
- Dark & Light themes

## Getting Started

```bash
flutter pub get
flutter run
```

## Build APK

```bash
flutter build apk --release
```
